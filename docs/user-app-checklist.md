# Чек-лист разработки пользовательского приложения
## Проект: Онлайн библиотека научных работ философа

---

## 📋 Описание проекта

Пользовательское веб-приложение для доступа к онлайн библиотеке научных работ философа. Приложение включает:
- Чтение работ в формате Markdown
- Семантический поиск по текстам работ
- ИИ-ассистент для помощи в изучении и разборе философских текстов
- Закрытая регистрация через систему заявок
- Персональные заметки и закладки
