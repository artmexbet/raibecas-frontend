# Управление пользователями

## Обзор

Страница управления пользователями предоставляет администраторам возможность просматривать список всех пользователей системы и управлять их статусом активности.

## Функциональность

### Список пользователей

**Маршрут**: `/users`

**Требуемые права**: `view_users`

#### Отображаемая информация

Таблица со следующими колонками:

- **Имя пользователя** - логин пользователя
- **Полное имя** - полное ФИО пользователя
- **Email** - адрес электронной почты
- **Статус** - активен/неактивен (отображается цветным тегом)
- **Заметок** - количество созданных заметок
- **Дата регистрации** - когда пользователь зарегистрировался
- **Последний вход** - время последней активности
- **Действия** - кнопки для управления пользователем

#### Возможности

1. **Сортировка** - по любой колонке
2. **Фильтрация** - по статусу (активные/неактивные)
3. **Пагинация** - настраиваемый размер страницы
4. **Деактивация/активация** - изменение статуса пользователя

### Деактивация пользователя

При нажатии на иконку деактивации/активации:

1. Открывается модальное окно с подтверждением
2. Администратор подтверждает действие
3. Статус пользователя изменяется
4. Таблица автоматически обновляется
5. Показывается уведомление об успехе/ошибке

**Важно**: Деактивированные пользователи не могут входить в систему и создавать новые заметки, но их данные сохраняются.

## Технические детали

### Используемые файлы

- `src/pages/UsersListPage.tsx` - компонент страницы
- `src/services/users.service.ts` - сервис для работы с API
- `src/types/index.ts` - типы данных пользователей
- `src/mocks/data/users.ts` - моковые данные
- `src/mocks/handlers/users.ts` - обработчики моков

### API Endpoints

```typescript
// Получение списка пользователей
GET /users

// Обновление пользователя (изменение статуса)
PATCH /users/:id
Body: { isActive: boolean }
```

### Интеграция с моками

Система автоматически переключается между моками и реальным API в зависимости от конфигурации:

```typescript
// src/mocks/config.ts
modules: {
  users: true, // true = использовать моки, false = реальный API
}
```
