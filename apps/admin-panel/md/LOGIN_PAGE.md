## 🔧 Использование

### Запуск в режиме разработки

```bash
cd apps/admin-panel
bun dev
```

Откройте http://localhost:3000 в браузере.

### Тестирование

Форма ожидает следующие данные:
- **Email**: валидный email адрес
- **Пароль**: минимум 6 символов
- **Запомнить меня**: опционально

### API интеграция

Форма отправляет POST запрос на:
```
POST /api/auth/login
Body: { email, password, remember }
```

Ожидаемый ответ:
```json
{
  "token": "jwt-token-here",
  "admin": {
    "id": "1",
    "email": "admin@example.com",
    "username": "admin",
    "role": "admin",
    "createdAt": "2026-01-09"
  }
}
```

### Обработка ошибок

- **401**: Неверный email или пароль
- **403**: Доступ запрещен (недостаточно прав)
- **Другие**: Общая ошибка сервера

## 🔐 Безопасность

- Токен сохраняется в `localStorage`
- Токен автоматически добавляется к заголовкам всех запросов
- При ошибке 401 пользователь автоматически перенаправляется на страницу логина
- Данные очищаются при выходе

## 🛠 Конфигурация

### Изменить URL API

Отредактируйте `src/constants/api.ts`:

```typescript
export const API_BASE_URL = process.env.API_BASE_URL || 'http://your-api-url/api';
```

Или установите переменную окружения:

```bash
export API_BASE_URL=http://your-api-url/api
```
