# Управление заявками на регистрацию

## Обзор

Страница управления заявками на регистрацию позволяет администраторам просматривать запросы от новых пользова��елей и принимать решения об одобрении или отклонении.

## Функциональность

### Список заявок

**Маршрут**: `/registration-requests`

**Требуемые права**: `view_registration_requests`

#### Отображаемая информация

Таблица со следующими колонками:

- **Имя пользователя** - желаемый логин
- **Email** - адрес электронной почты
- **Запрос** - текст заявки с обоснованием регистрации
- **Действия** - кнопки одобрения/отклонения

#### Возможности

1. **Сортировка** - по имени пользователя и email
2. **Просмотр деталей** - клик по строке открывает модальное окно
3. **Одобрение заявки** - создание пользователя в системе
4. **Отклонение заявки** - отказ в регистрации

### Работа с заявками

#### Просмотр деталей

При клике на любую строку таблицы:

1. Открывается модальное окно с полной информацией
2. Отображаются все данные заявки
3. Доступны кнопки "Одобрить", "Отклонить" и "Отмена"

#### Одобрение заявки

При одобрении заявки:

1. В системе создается новый пользователь
2. Пользователь получает возможность входа
3. Заявка удаляется из списка ожидающих
4. *(В будущем)* Отправляется email с подтверждением

#### Отклонение заявки

При отклонении заявки:

1. Заявка удаляется из системы
2. *(В будущем)* Может быть отправлен email с причиной отклонения

### Быстрые действия

В таблице доступны кнопки для быстрых действий:

- **Иконка "+"** (UserAddOutlined) - одобрить заявку
- **Иконка "удалить"** (UserDeleteOutlined) - отклонить заявку

## Технические детали

### Используемые файлы

- `src/pages/UserRequestsListPage.tsx` - компонент страницы
- `src/services/users.service.ts` - сервис для работы с API
- `src/types/auth.ts` - типы данных заявок
- `src/mocks/data/registrationRequests.ts` - моковые данные
- `src/mocks/handlers/registrationRequests.ts` - обработчики моков

### API Endpoints

```typescript
// Получение списка заявок
GET /registration-requests

// Одобрение заявки
POST /registration-requests/:id/approve

// Отклонение заявки
POST /registration-requests/:id/reject
```

## Использование

1. Войдите в систему как администратор
2. Перейдите в раздел "Заявки на регистрацию"
3. Просмотрите список ожидающих заявок
4. Кликните на заявку для просмотра деталей или используйте быстрые кнопки
5. Одобрите или отклоните заявку
